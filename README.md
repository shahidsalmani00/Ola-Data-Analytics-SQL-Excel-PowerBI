# Ola Data Analytics End-to-End Project

## Project Overview

This project focuses on analyzing Ola-inspired ride-booking data for Bengaluru using **SQL, Microsoft Excel, and Power BI**. The objective is to understand booking performance, customer and driver cancellations, vehicle preferences, ride trends, and booking value through data analysis and visualization.

The project follows an end-to-end data analytics workflow, from raw data preparation and SQL analysis to Excel reporting and interactive Power BI dashboards.

**Note:** This project uses synthetic ride-booking data created for learning, portfolio development, and skills revision. It does not contain actual Ola internal business data.

## Project Objectives

- Analyze overall ride-booking performance.
- Calculate successful booking and cancellation rates.
- Identify major reasons for customer and driver cancellations.
- Compare booking patterns across different vehicle types.
- Analyze booking value and ride-distance trends.
- Compare weekday and weekend booking activity.
- Develop an interactive Power BI dashboard for business reporting.
- Practice practical data analytics skills using SQL, Excel, and Power BI.

## Tools and Technologies

- **SQL:** Data querying, filtering, aggregation, joins, and business analysis.
- **Microsoft Excel:** Data validation, sorting, filtering, formulas, PivotTables, and summaries.
- **Power BI:** Interactive dashboards, KPI cards, charts, filters, and data visualization.

## Dataset Information

The dataset contains 100,000 synthetic ride-booking records for Bengaluru for October 2026.

Key fields include:

- Date and Time
- Booking ID and Customer ID
- Booking Status
- Vehicle Type
- Pickup Location and Drop Location
- Average VTAT and CTAT
- Customer and Driver Cancellation Information
- Incomplete Ride Reasons
- Booking Value
- Ride Distance
- Driver Ratings and Customer Ratings

The dataset represents seven vehicle categories: Auto, Prime Plus, Prime Sedan, Mini, Bike, eBike, and Prime SUV.

## Project Workflow

### 1. Data Preparation

- Reviewed the dataset structure and column types.
- Checked missing values, duplicate records, and data consistency.
- Prepared the data for analysis using SQL and Excel.
- Validated booking statuses and applicable fields.

### 2. SQL Analysis

SQL is used to answer business questions such as:

- How many bookings were successful?
- What percentage of rides were cancelled by customers or drivers?
- Which vehicle types have the highest booking volume?
- What are the most common cancellation reasons?
- How does booking value vary across different dates?
- How do weekday and weekend booking trends compare?

### 3. Excel Analysis

Excel is used for:

- Sorting and filtering booking records.
- Using formulas to calculate key metrics.
- Creating PivotTables and summary reports.
- Comparing booking statuses and vehicle categories.
- Analyzing booking values and daily trends.

### 4. Power BI Dashboard

The Power BI dashboard is designed to present:

- Total Bookings
- Successful Bookings
- Customer and Driver Cancellations
- Incomplete Rides
- Booking Value and Revenue Trends
- Vehicle Type Analysis
- Cancellation Reasons
- Daily and Weekend Booking Trends

Dashboard features may include interactive slicers for dates, vehicle types, and booking statuses.

## Key Business Questions

1. What is the overall booking success rate?
2. What are the main reasons for ride cancellations?
3. Which vehicle categories receive the most bookings?
4. How does booking value change across different days?
5. Are weekend bookings higher than weekday bookings?
6. Which operational issues contribute to incomplete rides?
7. How can booking data help identify opportunities to improve ride performance?

## Key Insights

The final insights will be documented after validating the dataset and completing the SQL queries, Excel analysis, and Power BI dashboard.

Potential areas of investigation include cancellation patterns, vehicle demand, booking-value distribution, and differences between weekday and weekend activity.
